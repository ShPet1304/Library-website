# Library | The Odin Project

## A classic-themed library application built as part of The Odin Project curriculum. This project demonstrates vanilla JavaScript DOM manipulation, object-oriented data management, and advanced CSS styling.

### Live Demo - https://shpet1304.github.io/Library-website/

### Features

    Interactive 3D UI: Books are displayed as cards that utilize a 3D flip effect on hover to reveal detailed information and actions.

    State-Driven Updates: Adding, removing, and updating books instantly re-renders the DOM, keeping the UI perfectly in sync with the underlying JavaScript array (similar to reactive state management).

    Responsive Layout: Cards automatically flow and space themselves evenly as the collection grows or shrinks.

    Add New Books: A clean, togglable form modal to input new titles, authors, page counts, and read status.

    Manage Collection: Toggle read/unread status or delete books directly from the back of their respective cards.

### Built With

    HTML5

    CSS3: Featuring 3D Transforms (transform-style: preserve-3d) and dynamic layouts.

    Vanilla JavaScript: Handling arrays, objects, and event-driven DOM manipulation.
